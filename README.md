# aws-static-website-s3-cloudfront-clickops
Static resume website deployed manually on AWS using S3, CloudFront, Route 53, ACM, and IAM best practices.
This project is part of my transition from Automotive ECU Validation & Verification into Cloud/DevOps.
The main focus of this project is the AWS deployment architecture, including S3 static hosting, CloudFront, Route 53, ACM, and basic IAM/security best practices.
